
# SQL Database Tools & Scripts

## Overview
A collection of SQL scripts designed to assist with database management, data analysis, data validation, and data quality assessment.

This repository contains reusable SQL queries that automate common database inspection and analysis tasks.

## Available Tools

| Tool | Description | ReadMe |
|---|---|---|
| [NULL Value Scanner](./null_value_scanner.sql) | Scans database tables and identifies columns containing NULL values, including their counts and percentages. | [NULL Value Scanner Documentation](./readme_null_value_scanner.md) |

## Usage
1. Browse the available tools in this repository.
2. Open the corresponding folder.
3. Read its README for instructions and details.
4. Open and execute the SQL script using a compatible database management system.

## Compatibility
SQL scripts may be designed for specific database management systems and SQL dialects.

Some queries can be adapted to other SQL dialects using an AI tool of your choice. Always review and test adapted queries before execution.

## Disclaimer
These scripts are provided for educational, development, and database analysis purposes. Always review queries and test them in an appropriate environment before executing them on production databases.
